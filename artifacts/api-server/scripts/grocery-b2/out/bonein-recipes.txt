[grocery] B2 — PUBLIC recipes whose plain chicken should probably be bone-in
REPORT ONLY. Nothing was changed.

Hans, September 28: a recipe wanting bone-in must SAY so. H2 now makes a
plain "chicken thighs" mean boneless skinless on the shopping list, which is
right for shopping and wrong for any recipe whose STEPS assume skin or bone.
This is the recipe-authoring side of the same rule.

recipe already NAMES its cut — which is Hans's rule working before it was
written down. The plain name is mostly a USER-authored shape, and a user's own
recipe is theirs to word.
